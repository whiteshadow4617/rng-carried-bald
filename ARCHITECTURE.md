# Code layout

The mod targets Forge 1.8.9 and keeps the event-driven client integration separate from pure text parsing and world rendering.

- `SpiderDropAlert` is the Forge entry point and event coordinator. It registers listeners and commands, owns persistent feature state, and processes client events without containing HUD drawing code.
- `HudPanelRenderer` draws the Slayer, Fishing, deployables-timer, and nearby-creature-health overlays from coordinator-owned state; the four panel backgrounds use their own persisted opacity settings.
- `HudLayoutEditorScreen` is the full-screen arranger. Each box is dragged by its body; its corner handle starts a resize (`resizedPercent(startPercent, travelPixels)` maps every two pixels to a 1% step in the axis the mouse travelled furthest, clamped to the shared 1%-100% range) and a size readout follows the cursor while dragging. There is no other resize path: the corner drag is the only way panel sizes change.
- `TrackerConfigScreen` is the `/tg` settings window: a NotEnoughFakepixel-style collapsible category tree (`Row` model with per-group `expanded` flags) on the left and scrollable feature cards (`Card` with CARD_TOGGLES/CARD_BUTTONS/CARD_SLIDER/CARD_FIELDS/CARD_NOTES kinds) on the right. It keeps no `GuiButton` widgets - every control is drawn and hit-tested itself through the `Hit` list - and routes each id to the existing `SpiderDropAlert` toggle/position/size/opacity API.
- `QuickNoteStore` owns the `/qn` pages: a plain-text file in the config folder holding `NotePage` records (heading plus body) separated by a `%%PAGE%%` marker, with headings on `%%TITLE%%` lines and marker-looking lines escaped. `QuickNoteScreen` is the pad - a searchable page list on the left (`QuickNoteStore.findPages` matches headings and bodies case-insensitively, `getPreview` titles each row) beside the heading field and the note box, which is wrapped into clickable display lines with a blinking caret, autosaving through the screen tick plus on page changes and close. `QuickNoteCommand` only raises a pending flag on the coordinator so the GUI opens after the chat screen has closed.
- The M7 dragon kill alert lives on `SpiderDropAlert`: `statueForDragon` resolves a sighting by name or by the nearest statue anchor, `pickDragonKillTarget` keeps only dragons within 20 blocks of the player and 15 of their own statue and picks the closest, and `updateDragonKillAlertFromClient` runs from the client tick behind the F7/M7 scoreboard gate, titling `KILL <DRAGON> DRAGON` in the statue colour through a hold window so it cannot flicker.
- `FishingSessionTracker` computes session-only tracked-creature efficiency and a Great White-only Fishing Festival personal best from local 1.8.9 catch announcements.
- `DropMessageParser` contains side-effect-free parsing for rare-drop lines, stack quantities, boss messages, and existing fishing announcements. `NefFishingFeatureParser` handles Fakepixel-specific notifier text and server/area gates. Parser tests do not need a running Minecraft client.
- `SlayerType` and `LegendaryCreature` hold the canonical categories and recognized message markers used by the parser and tracker.
- `M7OverlayRenderer` owns normal F7/M7 and Fakepixel dragon-sidebar detection, M7 final-phase and dragon-spawn state, NEF 1.2.4-style relic-area boxes, dragon-to-statue mapping, world-unload cleanup, and world-space outlines. The M7 area boxes appear on the final-phase cue; the persisted “keep after dragon spawn” setting defaults ON and can be switched OFF to hide them after the first dragon. Named boss armor-stand labels are associated with nearby Wither bodies for the four F7 bosses. Feature switches and settings persistence stay in `SpiderDropAlert`.
- The small command classes keep command syntax out of the event handlers.

## Validation

Use Java 8 and run `bash gradlew clean test build`. The unit tests cover parsing, timers, settings persistence, local info-panel field extraction, standard and Fakepixel-style M7 scoreboard recognition, dragon mapping, and the pure rendering geometry helpers. They do not replace an in-game Hypixel runtime check.
